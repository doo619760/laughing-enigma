## California Complaint Format Requirements

### Formatting Specifications
- **Font:** Times New Roman, 13 point
- **Spacing:** Double-spaced throughout
- **Line Numbers:** 1-28 on left margin (California pleading paper)
- **Margins:**
  - Left: 1.5 inches (to accommodate line numbers)
  - Right: 1.0 inch
  - Top: 1.0 inch
  - Bottom: 1.0 inch
- **Page Size:** 8.5 x 11 inches (Letter)

### Required Sections

1. **Attorney Header** (top left)
   - Attorney name and State Bar number
   - Law firm name
   - Complete address
   - Telephone number
   - Email address
   - "Attorney for Plaintiff" designation

2. **Court Heading** (centered)
   - "SUPERIOR COURT OF THE STATE OF CALIFORNIA"
   - "FOR THE COUNTY OF [COUNTY NAME]"

3. **Caption** (case style)
   - Plaintiff name(s)
   - "Plaintiff," designation
   - "vs." centered
   - Defendant name(s)
   - "Defendant," designation
   - Case Number box (right side)
   - Title: "COMPLAINT FOR:"
   - Numbered list of causes of action

4. **PARTIES** section
   - Paragraph identifying each plaintiff
   - Paragraph identifying each defendant
   - Residency and jurisdictional facts

5. **JURISDICTION AND VENUE** section
   - Basis for court's jurisdiction
   - Basis for proper venue
   - Amount in controversy statement

6. **GENERAL FACTUAL ALLEGATIONS** section
   - Background facts
   - Chronological narrative
   - Relationship between parties
   - Context for claims

7. **CAUSES OF ACTION** (separate sections)
   - Each cause numbered (FIRST CAUSE OF ACTION, SECOND CAUSE OF ACTION, etc.)
   - Cause name centered under heading
   - Reallege/incorporate prior paragraphs
   - State elements of the cause
   - Specific facts supporting each element
   - Damages resulting from the cause

8. **PRAYER FOR RELIEF** section
   - "WHEREFORE" introductory clause
   - Numbered list of requested relief:
     1. General damages
     2. Special damages
     3. Costs of suit
     4. Attorney's fees (if applicable)
     5. Prejudgment interest
     6. Other relief as appropriate

9. **Signature Block**
   - "Dated:" line
   - "Respectfully submitted,"
   - Signature line
   - Attorney name
   - "Attorney for Plaintiff" designation

## Legal Drafting Standards

### Allegations Must Be:
- **Specific:** Include dates, amounts, locations, and details
- **Clear:** Use plain language where possible
- **Factual:** State facts, not legal conclusions
- **Chronological:** Present events in logical order
- **Complete:** Include all material facts
- **Consistent:** No contradictions between allegations

### Legal Writing Style:
- Use active voice
- Write in third person
- Use present tense for current facts, past tense for historical facts
- Number all paragraphs consecutively
- Use proper legal terminology
- Avoid argumentative language in factual sections
- Keep sentences and paragraphs reasonably short
- Use "Plaintiff" and "Defendant" after initial identification

### Incorporation by Reference:
- Use standard language: "Plaintiff realleges and incorporates by reference paragraphs 1 through [X] as though fully set forth herein."
- Do this at the start of each cause of action

### Damages Allegations:
- Plead general damages ("according to proof")
- Plead special damages with specificity if known
- Include all categories of damages
- State damages are "in excess of [jurisdictional minimum]" or specific amount
- Include "As a direct and proximate result" language
